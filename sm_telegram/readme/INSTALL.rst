1. Place ``sm_telegram`` folder in your Odoo addons path.
2. Restart Odoo server.
3. Go to **Apps**, update the Apps List, search for *Telegram Integration Advanced* and click **Install**.

Prerequisites
~~~~~~~~~~~~~

- Your ``web.base.url`` system parameter must be set to a **public HTTPS** domain.
- The domain must be reachable from Telegram servers (not localhost).
- Telegram only accepts HTTPS webhook URLs.
